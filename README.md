# MMO Shop Next.js
Website bán hàng số giống mô hình shopmmo: sản phẩm, ví tiền, nạp tiền, mua hàng, lịch sử, admin.

## Chạy thử
```bash
npm install
cp .env.example .env
npx prisma db push
npm run dev
```

## Tài khoản admin mẫu
Tạo user trong database với role ADMIN hoặc chỉnh bằng Prisma Studio.
